## 🚀 Featured Project

<details open>
<summary><b>🏢 DigitalMSME — Full-Stack SaaS for Indian MSMEs</b></summary>

<br/>

A multi-app platform serving Indian small business compliance and verification needs — PAN, GSTIN, KYC, e-invoicing, and vehicle verification — built and iterated on since mid-2025.

| Aspect | Detail |
|---|---|
| **Apps** | React/TypeScript main website · separate chatbot dashboard · Flutter mobile app · React CMS admin panel |
| **Backend** | Node.js/Express (TypeScript) + Spring Boot, shared PostgreSQL, JWT auth |
| **Architecture** | Dual-database setup (auth DB separate from services DB), cross-app session sharing via localStorage |
| **Key builds** | Real-time streaming chat (SSE), wallet/transaction system with immutable ledger + Razorpay integration, org admin portal with typed DTOs and Zustand session store |
| **Design** | Custom navy/saffron design system across apps |
